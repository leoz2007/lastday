# Capsule 51 · Propriété intellectuelle

Texte de la voix off (296 mots).

## Scène 1 · Accroche

Avec l'IA générative, la propriété intellectuelle pose trois questions distinctes : ce que vous envoyez au modèle, ce qu'il produit, et le code qu'il écrit. Les mélanger, c'est rater des risques. Voici des principes généraux, pas un avis juridique.

## Scène 2 · Ce que vous envoyez au modèle

Première question : ce que vous envoyez. Un document confidentiel, un texte sous droits, un fichier client : avez-vous le droit de le transmettre ? Lisez aussi le contrat du fournisseur : vos données peuvent-elles entraîner ses modèles ? Et combien de temps sont-elles conservées ?

## Scène 3 · Ce que le modèle produit

Deuxième question : ce que le modèle produit. Un texte ou une image générés sont-ils protégés ? C'est incertain : la réponse varie selon les pays, et dépend de la part humaine dans le résultat. Autre risque : une sortie qui ressemble trop à une œuvre existante, comme un logo proche d'une marque connue.

## Scène 4 · Le code généré

Troisième question : le code généré. Il peut reproduire des extraits de code existant, soumis à une licence, c'est-à-dire à des conditions de réutilisation. Certaines licences imposent, par exemple, de publier le code qui en dérive. Vos développeurs doivent donc vérifier, comme pour tout code récupéré.

## Scène 5 · Ce que ça change côté produit

Côté produit, quatre bonnes pratiques. Des règles d'usage claires : quelles données, quels outils. Une revue humaine avant toute publication. Une traçabilité de ce qui est généré. Et des clauses contractuelles, avec votre service juridique : c'est lui qui tranche.

## Scène 6 · Questions à poser au cadrage

Au cadrage, posez trois questions. Quelles données avez-vous le droit d'envoyer au modèle ? Qui relit les contenus générés avant publication ? Et le service juridique a-t-il validé le contrat et les règles d'usage ?

## Scène 7 · À retenir

À retenir : trois questions distinctes, l'entrée, la sortie, et le code. Des règles, une revue humaine, de la traçabilité, et l'avis du juridique. Prochaine capsule : les contrats avec un fournisseur de modèle de langage.
